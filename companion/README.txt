港股情緒雷達 V2－富途本機連接器
====================================

用途
----
讓公開的「港股情緒雷達」網站讀取你已登入的富途股票討論頁。帳號、密碼、
驗證碼及 Cookie 都留在這部 Windows 電腦，不會傳到網站。

安裝與使用
----------
1. 需要 Windows 10/11、Google Chrome、Python 3.11 或以上版本。
2. 雙擊「啟動富途連接器.bat」。首次執行會建立 .venv 並安裝 Playwright。
3. 保持黑色視窗開啟。
4. 回到港股情緒雷達網站，按「重新檢查」。
5. 按「開啟富途官方登入」，在新 Chrome 視窗自行完成登入／驗證碼。
6. 回到網站按「我已完成登入」。之後開始分析時會同步抓取富途討論。

私隱與限制
----------
- 連接器不提供輸入密碼的欄位，也不會把登入 Cookie 傳送到網站。
- 本工具只讀取目前股票頁面可見的討論文字，不執行交易或修改富途帳戶。
- 富途頁面結構更新、驗證或存取限制可能令抓取暫時失效。
- 使用者應自行確認其使用方式符合富途服務條款及所在地法律。

停止
----
關閉連接器視窗，或在視窗內按 Ctrl+C。
