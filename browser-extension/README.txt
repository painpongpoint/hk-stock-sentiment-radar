港股情緒雷達 V2－富途瀏覽器擴充功能
======================================

用途
----
在你已登入的富途官方網頁內，讀取指定股票頁面上可見的討論文字，並交給
「港股情緒雷達」作情緒分析。擴充功能不讀取或傳送密碼、驗證碼與 Cookie。

Chrome 安裝方法
---------------
1. 解壓縮下載的 ZIP 檔案。
2. 在 Chrome 網址列輸入 chrome://extensions/。
3. 開啟右上角「開發人員模式」。
4. 按「載入未封裝項目」，選擇含有 manifest.json 的資料夾。
5. 回到港股情緒雷達網站並重新整理頁面。

Edge 安裝方法
-------------
1. 解壓縮下載的 ZIP 檔案。
2. 在 Edge 網址列輸入 edge://extensions/。
3. 開啟「開發人員模式」。
4. 按「載入解壓縮的擴充功能」，選擇含有 manifest.json 的資料夾。
5. 回到港股情緒雷達網站並重新整理頁面。

使用流程
--------
1. 網站顯示「擴充功能已連接」後，按「開啟富途官方登入」。
2. 在富途視窗自行完成登入及驗證。
3. 返回網站按「我已完成登入」。
4. 輸入港股編號並按「抓取及分析」。
5. 擴充功能會開啟相應富途股票頁，讀取頁面可見討論並提交至分析 API。

安全與限制
----------
- 只允許本機預覽及指定的港股情緒雷達網站使用。
- 只處理富途網頁上已顯示的討論文字，不執行交易或修改帳戶。
- 富途網站版面、驗證或存取限制變更時，擷取規則可能需要更新。
- 使用者應自行確認使用方式符合富途服務條款及所在地法律。
